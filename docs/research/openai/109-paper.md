## 1. Main theorem, corollaries, model

Model (Section 2): one deterministic Turing machine with one fixed finite alphabet and one fixed finite number of one-dimensional tapes; a step reads/writes at most one cell per tape and moves each head by at most one cell. Input `x#y`, `x, y in {0,1}^n`, most significant bit leftmost; output `bin_{2n}(val(x) val(y))`. `lg n = max{ceil(log2 n), 1}`. The O(n log n) multiplier of Harvey and van der Hoeven [15] is used as an ordinary (non-recursive) subroutine on inputs of O(rp) = o(n) bits.

Theorem 1. There is one such machine A computing the exact product for every n >= 1 with worst-case time `T_A(n) = O(n (lg n)^{1-kappa})`, `kappa = 2^{-182}`. (The constants/thresholds are "extremely large"; below a fixed cutoff schoolbook multiplication is used.)

Corollary 2 (Section 10). Same model and bound for exact division (`bin_n(floor(a/b)) # bin_n(a - b floor(a/b))`, b > 0) and integer square root (`bin_n(floor(sqrt a))`), via Brent's Newton iterations with the explicit error recursion `|1 - c x^+| <= eps^2 + 6 delta` at t fractional bits, capped doubling of precision, and final exact remainder / square tests.

Section 11 (matrix transposition). Via [16, Cor. 6.2], a row-major `n1 x n2` array of b-bit strings (entry (i,j) at `n2 i + j` moved to `n1 j + i`) is transposed in `O(m (lg m)^{1-kappa})`, `m = n1 n2 b`; in particular `k x k` binary in `O(k^2 (lg k)^{1-kappa})`. Section 1.7 notes the address procedure forms XOR combinations of data, so it lies outside the "pure data movement" models of [16].

Section 1.8: the complex network (Proposition 8) is reused in the companion "explicit power saving for the exact DFT" paper (exact complex-register model with unit-cost field ops and O(log n)-bit word addressing, one supplied root of order < 1024 n^3; cost `O(n (log n)^{theta} (log log n)^{4-theta})`, `theta = log_m(m - Delta/W*)`, `m = 10^6`, `W* = 2^71`, `Delta = 6871402692000000`). I checked: `Delta = 2N - 2L_c = W_c m - s_c` exactly, and `W_c < 2^71`, so that paper simply pads the role count to a power of two. The "Finite tensor savings" paper is the nonuniform existence version (a "finite win" for some nonmonomial 2x2 matrix, amplified by tensor powers).

## 2. The reduction chain (Figure 1), with the key identity at each step

(a) Radix digits (9.2.1, 9.2.3, 9.6). `b = ceil(log2 n)`, `p = 6b`, `d = floor(b^eps)`, `K = floor(d^c)`; T a power of two in `[4n/b, 8n/b)`; `r = 2^{ceil(log2 T / d)}`, `l = log2 r`; axis lengths `t_i in {r/2, r}` with `prod t_i = T`, `t_d = r`. Inputs become polynomials in `2^b` with `q = ceil(n/b)` digits; the product has degree `2q - 2 < 2n/b <= T/2 < S`, so cyclic convolution mod `x^S - 1` has no wrap, and `0 <= c_j <= q(2^b - 1)^2 < 2^{3b}` (41). Digit `a_j` is stored as the exact grid value `a_j 2^{-b-2}` (numerator `a_j 2^{p-b-2}`, norm < 1/4).

(b) CRT address map (9.3). Distinct odd primes `s_i` with `(1-2eta) t_i < s_i <= (1-eta) t_i`, `eta = 1/(4d)`, hence `T/2 < S = prod s_i < T` and `gcd(s_i, t_i) = 1`. With `P_i = prod_{j<i} s_j`, `mu_i = P_i^{-1} mod s_i`,
`Phi: C[x]/(x^S-1) -> C[x_1..x_d]/(x_i^{s_i}-1), x -> prod_i x_i^{mu_i}`
is an algebra isomorphism (x has order S in the target monomial group) and so preserves cyclic convolution. On indices: `k = sum_j a_j P_j` (mixed radix, `0 <= a_j < s_j`) goes to axis coordinates
`b_i = a_i + mu_i sum_{j<i} a_j P_j  (mod s_i)`  (42),
i.e. `b_i = mu_i k mod s_i`. Implemented as d "triangular controlled shifts" (Lemma 4) processed `i = d, d-1, ..., 1` so that controls are still original digits, inside the padded box `prod [0, t_i)` with zero records at invalid addresses, followed by an axis reversal by O(d^2) adjacent chunk swaps. Cost `O(T p d^2 (1 + l^tau))`.

(c) Gaussian resampling with permutations retained (Section 8). One-dimensional (Lemma 19): for coprime `s < t`, `(P_s u)_j = u_{tj}`, `(P_t v)_k = v_{-sk}`, there are contractions A, B0 with
`P_s F_s = 2^{2 alpha^2} B0 P_t F_t A`  (33),
derived from HvdH's `T P_s F_s = P_t F_t S` and `||N - I|| < 2^{-alpha^2 theta}`, `N = C T D`, `A = S/2`, `B0 = D' J' C`. Tensor version (Lemma 20): `R F_s = 2^gamma B0 Q F_t A`, `gamma = 2 d alpha^2` (35). The permutations `R = tensor P_{s_i}`, `Q = tensor P_{t_i}` are never executed as sorts.

(d) Bluestein chirp and permutation cancellation (Lemma 21). With `a_j = exp(-pi i sum_i s_i j_i^2 / t_i)` (period `t_i` in coordinate i, all `t_i` even):
`Q F_t u = a . (a * (a . u)) / T`  (36),
`(R F_s^+)((R F_s u).(R F_s v)) = u * v / S^2`  (37),
the latter from `F_q^+ R_c = R_{c^{-1}} F_q^+` for a unit c mod q, so `R F_s^+ R = F_s^+`. Conjugating input and output of an `R F_s` algorithm gives `R F_s^+`.

(e) Phase twist to the negacyclic ring (9.4). `R_r = C[y]/(y^r + 1)`, `zeta = e^{pi i / r}`, `Theta: C[x_d]/(x_d^r - 1) -> R_r, x_d -> zeta y` (well defined since `(zeta y)^r = (-1)(-1) = 1`), diagonal on monomial bases (`coefficient k` times `zeta^k`). Wrap check: if `k + l = j + h r`, `h in {0,1}`, then `zeta^{k+l} (-1)^h = zeta^j`. Hence `M_C(f,g) := D_- iota^{-1} M_r(iota D_+ f, iota D_+ g) = f * g / T` where `(D_+- f)_{j,k} = zeta^{+-k} f_{j,k}`, `iota` reads the last axis as the polynomial suffix, and `M_r(f,g) = f * g / (rM)` is the normalized ring convolution on the first d-1 axes.

(f) Synthetic (Nussbaumer) transforms (Section 6). `omega_t = y^{2r/t}` for t | 2r a power of two; `(F_t^- z)_j = (1/t) sum_k omega_t^{-jk} z_k`, `F_t^+` with `+jk`. Lemma 15: `sum_{k<t} omega_t^{jk} = t [t | j]` (proof: shift k by `t/2^{v+1}` multiplies the sum by `y^{r j_0} = -1`, and R_r has no 2-torsion), so `F_t^+ F_t^- = t^{-1} I`. DIF step (27): `(F_t^- z)_{2h+b} = (1/(t/2)) sum_k (omega_t^2)^{-hk} omega_t^{-bk} (z_k + (-1)^b z_{k+t/2}) / 2`. Outputs land in bit-reversed order `B_t`; the implemented exact operators are `B_t F_t^-` and `F_t^+ B_t^{-1}` (28). Convolution theorem used: `F_t^-(f * g) = M (F_t^- f)(F_t^- g)`, `M = prod t_i`. Twiddles are monomials `y^E`, `E = -sum_i (2r/u_i) b_i k_i mod 2r` (29), implemented as a split-at-`r - s`, swap, negate-tail, times `(-1)^e` for `E = e r + s`.

(g) Signed packing / Kronecker substitution (Lemma 17). `f = 2^{-p}(a + i b)`, `g = 2^{-p}(c + i e)`, `B0 = 2^{4p}`, `A_u = u(B0) = sum_j u_j B0^j`, `|A_u| < B0^r / 2`; coefficients of products satisfy `|h_j| <= r 2^{2p} < 2^{3p} < B0/2` (31), so centered residues mod B0 with carries `rho_j in {0,1}` recover `h_j` exactly; negacyclic reduction `H_j = h_j - h_{j+r}`, `|H_j| <= r 2^{2p}`; output `Q_p(fg/r)` with error `< sqrt2 2^{-p}`. Four HvdH products on 4pr-bit integers.

(h) Precision and carry recovery (9.7). Error budget: `E_ring = M(3L+2) < 5TL`, computed complex convolution error `< 6TL h_p`, chirp `< 8TL h_p`, source transform `E_s = 9 2^gamma T L` (43), `E_w = S(3E_s + 2) < 28 2^gamma T^2 L`; final
`2^{2b+4} S . 28 2^gamma T^2 L . 2^{-6b} < 448 b 2^{-b+gamma} <= 448 b 2^{-3b/4} < 1/2`  (44),
so rounding to nearest integer is exact. Carries with `Q0 = 2^b`: `k_0 = 0`, `d_j = (c_j + k_j) mod Q0`, `k_{j+1} = floor((c_j + k_j)/Q0)`, invariant `sum_{h<j} c_h Q0^h = sum_{h<j} d_h Q0^h + k_j Q0^j`, bound `0 <= k_j <= q(Q0 - 1) < Q0^2`.

Cost table (Table 1, costs divided by `V = Tp = Theta(n)`): `dK`, `pK^{tau-1}`, `l d^{lambda'}`, `d^2(1 + l^tau)`, `d p^{1/2+delta} alpha`, `d p^delta`, `log(rp)`, `p^delta`, `1`. Margins (45): `g1 = 1 - eps(1+c) > 1/2`, `g2 = eps c (1 - tau) = 2^{-181}`, `g3 = eps(1 - lambda') = 2^{-129}`, `g4 = 1 - tau - eps(2 - tau) > 2^{-51}`, `g5 = 1/4 - delta - 3eps/2 > 1/8`, `g6 = 1 - delta - eps > 1/2`, `g7 = eps = 2^{-75}`; `min g_i = 2^{-181} = 2 kappa`, the factor 2 absorbing fixed powers of log p.

## 3. The two finite networks (Section 3)

Constants: `h = 100`, `v = C(100,3) = 161700`, `N = v^3 = 4227952113000000`, `m = h^3 = 10^6`, `I = 3v^2 = 78440670000` invocations. T = 3-subsets of [h]. Data banks `X_a, Y_a`, `a in T^3`. ## 5. Mixed-radix / lexicographic / digit / CRT / carry uses, by location

- 2.1: arrays on `[a_1] x ... x [a_t]` in lexicographic order, first coordinate most significant; a trailing B-bit record = final field [B]; adjacent irrelevant fields collapse to one field of product length; row = `{p} x {r} x [B]`. Self-delimiting code `Gamma(v) = 0^{b_v - 1} bin_{b_v}(v)` (1).
- Lemma 3 (radix q): permute two radix-q digit values; move one digit preserving order of intervening positions; split on a digit, pointwise map, merge; cyclic row split `r = Wg + w` into W streams and merge. All O(V) by splitting into q^2 or q streams.
- Lemma 4: `y -> y + a(controls) mod Q`, `Q = q^b`, target after its controls (split fiber at `Q - a`, swap pieces); `y -> cy mod Q` for fixed unit c via `j = floor(cy/Q)` and `y' + jQ = 0 mod c` (c pieces); negation = block reversal. Rational denominators prime to q are reduced mod q^b by extended Euclid.
- 3.4 / 4.1-4.2: two chunks as vectors H, D of m fields of b digits over `Z/q^b Z`; shear `Phi_M`; the radix is coprime to all denominators of the fixed rational matrices.
- Lemma 12: `[2^u]` embedded in `[q^e]` by numeric order; top rho digits as row field; base-m digit decomposition `e - rho = sum a_j m^j` drives the piece partition.
- Section 5: K-bit chunks, selected offset rho in each; slots of f chunks; `x_{h,j}` bit at position `rho + jK` of slot h; Lemma 13 uses mixed-radix record strides `sigma_h` and ranks; Appendix A generalizes to grouped rectangles `[n_nu] x prod_h [a_{nu,h}]` with a tag template.
- 6.1: address slots `a-1..0` of an axis of length `2^a`; after s DIF levels the top s slots hold frequency bits 0..s-1; bit reversal `rev_a`; twiddle index `k = sum_{v<h} 2^v x_v`; (29) exponent mod 2r; monomial `y^E`, `E = er + s`.
- 6.2: layout L: `b = (l-1) mod K`, `q = floor((l-1)/K)`; prefix of listed slots `(i, l-1)` for long axes and `(i, h)`, `h < b`; chunk order changed from `(1,1),(1,2),...,(D,q)` (axis-major) to `(1,1),(2,1),...,(D,1),(1,2),...` (chunk-index-major) by <= Dq - 1 K-chunk exchanges, i.e. a D x q transpose of chunk positions; worked example l = 6, K = 2.
- 7: Kronecker base `B0 = 2^{4p}`, two's-complement block encoding with carry `gamma in {-1, 0}`, centered extraction with carry `rho in {0,1}`, negacyclic fold `j + r -> j`.
- 8.1: ordered selection indices `q_j = floor(tj/s + 1/2)` generated by counters `tj = s f_j + e_j` with single carry `c_j = [e_j + rho >= s]`.
- 8.2: axis exposure by adjacent interchanges of l- or (l-1)-bit fields; unequal widths by peeling the leading bit.
- 9.2.1: `t_i in {r/2, r}`, `prod t_i = T`; 9.3: mixed radix `k = sum a_j P_j`, (42), nested lexicographic scan of `prod [0, t_i)` with `a_d` outermost; 9.6: radix-`2^b` digits read least-significant-first; 9.7.2: carry recurrence and invariant; 11: row-major address `n_2 i + j`.

## 6. Self-contained lemmas suitable for a Lean mixed-radix / exact-circuit library

1. Digit convolution with carries equals the product. For `a = sum_j a_j Q^j`, `b = sum_j b_j Q^j` (digits in [0,Q)), `c_k = sum_{i+j=k} a_i b_j`, then `ab = sum_k c_k Q^k`; with `k_0 = 0`, `d_j = (c_j + k_j) mod Q`, `k_{j+1} = (c_j + k_j) div Q`: `sum_{h<j} c_h Q^h = sum_{h<j} d_h Q^h + k_j Q^j` for all j, `d_j in [0,Q)`, and if `c_j <= q(Q-1)^2` then `k_j <= q(Q-1)`. (9.7.2; also (41).) Purely over ℕ.
2. Three shears give an interchange, in any abelian group: `(H,D) -> (H, D-H) -> (H+(D-H), D-H) = (D, D-H) -> (D, H)`. And Lemma 10's local form `(h,d) -> (h, d+h) -> (d+h, h) -> (d+h, d)`. Together with `Phi_{M'} Phi_M = Phi_{M'+M}`, `Phi_M` a bijection of `G^m x G^m x Spectators` for any additive group G and integer (or `Z/QZ`) matrix M.
3. Lower-triangular Bruhat form (Lemma 9) for matrices over a field, and the "exactly rank(A) transpositions" count. Also: a lower-triangular invertible change of m coordinates can be done by m sequential updates each depending only on earlier coordinates (so each is a Lemma-4 controlled shift).
4. Recursion lemma: if `F_0 <= c` and `F_k <= a F_{k-1} + c` with `0 < a < m^tau`, then `F_k <= C m^{k tau}` (`C = c . sum_j (a/m^tau)^j` if a > 1, `c(k+1) <= C m^{k tau}` if a <= 1); Section 5's variant `F(e) <= a F(e/m) + C e^lambda` with `a < m^lambda` giving `F(e) = O(e^lambda)` plus the leaf term `a^j u <= e^sigma u^{1-sigma}`. Also the base-m digit decomposition step: `sum_j a_j m^{j tau} = O(e^tau)` when `0 <= a_j < m`, `e = sum a_j m^j`.
5. Lemma 5 (network correctness) for arbitrary h >= 4 and in both scalar domains: with T = 3-subsets of Fin h, define V, G, J, R as in 3.1; then `JV + RG = I` on `R^T` (bit: coefficient `|S cap T| mod 2` minus the intersection-one indicator; complex: `(|S cap T| - 1)/2` plus `-(|S cap T| - 1)/2` on even-intersection distinct pairs); the eight-row schedule is `y <- y + x` with scratch restored for arbitrary scratch values; three stages give `(X, Y) -> (-Y, X)`. Finite check feasible for small h (done for h = 4..7); the general statement is a Finset-sum identity.
6. Lemma 6 telescoping: for a network of wires each with a chain of vertices, `sum_e (dim U_head(e) - dim U_tail(e)) = sum_w (dim U_sink(w) - dim U_source(w))`; and `sum_e |..| = signed sum + 2 (total loss)`. Pure combinatorics on lists.
7. Bilinear-form facts: `<t_S, t_T> = |S cap T| - 1` for `x^T (I - J/9) y` on `Q^h` with |S| = |T| = 3; nondegeneracy (eigenvalues 1, 1 - h/9); over F2, triple indicators have norm 1 and even-intersection triples are orthogonal; nondegenerate nonalternating symmetric F2-spaces have orthonormal bases (`w+a, w+b, w+a+b` absorption).
8. Phase/weight identities (Prop 8): `wt(z + w) = wt z + wt w - 2|supp z cap supp w|`; additivity of wt mod 4 on orthogonal vectors; `q_{U perp E} - q_U = sum_{v in B} wt(v)[v.x] mod 4` for an orthonormal basis B of E; `i^{eps[s]} = (1+i^eps)/2 + ((1-i^eps)/2)(-1)^s`; `H diag(1,-1) H = X`; `P_M X_v P_M^{-1} = X_{Mv}`.
9. 2x2 matrix identities over Z[i,1/2]: (13), (14), (17), (18) and the scalar `b^D`. Trivial `decide`/`norm_num` targets.
10. Lemma 13's integer identity (21): the eight parity-controlled updates on Z^2 flip the parity of u iff c = 1, preserve `u div 2`, `w div 2`, and restore w; displacement <= 4. Finite check over parity classes.
11. Synthetic transform algebra over `Z[y]/(y^r + 1)` (or any commutative ring with no 2-torsion): `sum_{k<t} omega_t^{jk} = t [t | j]`, `F_t^+ F_t^- = t^{-1} I`, `F_t^-(f * g) = M (F_t^- f)(F_t^- g)` (cyclic convolution theorem with synthetic roots), the DIF recursion (27), and the bit-reversal statement "output j sits at slot rev_a(j)". These are direct FDRS/Cooley-Tukey-style statements with roots that are signed coefficient permutations.
12. Negacyclic twist identity: if `zeta^r = -1` then `x -> zeta y` is a ring isomorphism `R[x]/(x^r - 1) -> R[y]/(y^r + 1)`, diagonal on monomials, and `(f *_cyc g)_j = zeta^{-j} ((D_+ f) *_neg (D_+ g))_j` where `(D_+ f)_k = zeta^k f_k`.
13. CRT index map of 9.3: for pairwise coprime `s_1..s_d`, `P_i = prod_{j<i} s_j`, `mu_i = P_i^{-1} mod s_i`, the map `k -> (mu_i k mod s_i)_i` is a bijection `Z/S -> prod Z/s_i` preserving addition, and in mixed-radix digits `k = sum a_j P_j` it reads `b_i = a_i + mu_i sum_{j<i} a_j P_j mod s_i` (unipotent-triangular in the digits, invertible by processing i = 1..d). Also "numerical order of k = lexicographic order of `(a_d, ..., a_1)`".
14. Lemma 21 (37) algebraic core: `F_q^+ R_c = R_{c^{-1}} F_q^+` for a unit c mod q; tensoring; `R F^+ R = F^+`; chirp identity (36) `(1/T) a_j a_{j-k} a_k = exp(2 pi i sum s_i j_i k_i / t_i)`. Over a cyclotomic field these are exact.
15. Signed Kronecker substitution (Lemma 17): if `|u_j| <= 2^p`, `B0 = 2^{4p}`, then `A_u = u(B0)` satisfies `|A_u| < B0^r/2`, and product coefficients `|h_j| < B0/2` are recovered from `A_a A_c` by centered residues with carries in {0,1}; two's-complement block encoding with final carry `gamma_r = -1` iff negative.
16. Lemma 12's order fact: the numeric embedding `[2^u] -> [q^e]` (`q^e >= 2^u`) preserves lexicographic radix order, so padding needs no digit conversion.

## 7. Surprising, unclear, or possibly wrong

- The paper is not self-contained: it imports from HvdH [15] the O(n log n) multiplier, Theorem 4.2 (Gaussian identity), Lemma 4.6, Prop. 4.7, Lemmas 4.8-4.12 (the actual S', J', D' algorithms and their error bounds), Lemma 2.12 (root approximation) and Lemma 5.1 (primes in intervals); from [16, Cor. 6.2] the transposition reduction. Everything analytic about resampling is black-boxed; only its interface (33)/(35) and the retained permutations are new.
- The two networks are "crossed": the bit (F2-scalar) network carries rational labels with the form `I - J/9`, the Gaussian-dyadic network carries F2 labels. This is deliberate (3.3: "The scalar domain need not equal the label field") but is easy to misread.
- The asymmetry of deficits: `W_b m - s_b = N - 2L_b` but `W_c m - s_c = 2N - 2L_c`, because the rational interface spends an extra N ranks on the source matrices `-P_{U_a}` (first X_a edge has matrix `2P_{U_a}`, rank 1 at zero dimension change). This is why `L < N/2` is required; `L/N = 100/539, 101/539` leave comfortable room.
- The only decreasing edges are center 3 -> 4; each central wire goes `B tensor F -> A tensor F -> B tensor F -> A tensor F` (gain h, lose h, gain h). The loss total `L = I c h` is tiny relative to N because `I c h / N = 3 c h / v`.
- Where kappa really comes from: not from the network deficit directly but from the chunk-exchange row `p K^{tau-1}` with `K = d^c`, `d = p^eps`, i.e. from the product of three tiny exponents `eps . c . (1 - tau) = 2^{-75} 2^{-56} 2^{-50}`. The network's deficit only fixes `1 - tau = 2^{-50}`; eps and c are chosen conservatively and "no optimization is claimed".
- The complex network's role count `W_c ~ 1.87e21` just fits under `2^71`, which the companion DFT paper uses as `W*`; there the saving is `Delta = 2N - 2L_c`, consistent with Prop 8.
- Lemma 13's correctness depends on the physical requirement (Lemma 4) that the rotated target chunk follow its two control chunks, hence up to 16 Lemma-12 swaps per packed call; the time bound hides these in `O(V L^tau)`. The exceptional-set repair is a worst-case deterministic argument (depends on addresses only).
- In Prop 11 the cyclic row split assigns arbitrary genuine rows to scratch roles; correctness for arbitrary scratch values (Lemma 5) is essential, not a convenience. Padded zero rows are only needed to make the row count divisible by W^k.
- Minor presentational points: Section 9.2.2's η < 1/4 needs d >= 2; Section 5.3's `q_0 K >= k_0 log2 W` needs K >= 1 "for sufficiently large p" even though K = floor(d^c) with c = 2^{-56} is 1 for astronomically long ranges of p (d^c >= 2 only when d >= 2^{2^56}); the asymptotic claims `K/log p -> infinity`, `l/K -> infinity` are therefore only meaningful far beyond any physical input, which the paper acknowledges ("constants and thresholds are extremely large"). I found no step that is wrong; the displayed numbers all recompute exactly, and the Lemma 5 identity is independent of h.
- Lemma 9's statement allows "at most one [one] in each row and column" and "exactly a ones" — fine; but note the factorization is used only for its count, and the paper never exhibits the prime q nor the rational tables (they are "compiled into one fixed machine description").
- The error constant `E_ring = M(3L + 2) < 5TL` is stated loosely (M = T/r so this is far from tight); harmless.
