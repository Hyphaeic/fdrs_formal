## 1. Main theorem and corollaries

**Theorem 1.1.** For every fixed real `0 < δ < 1/3` there is a deterministic polynomial-time algorithm `R_δ` mapping each 3-CNF formula `ϕ` to a nonempty finite simple graph `G_ϕ` with: `ϕ` satisfiable ⇒ `G_ϕ` is 3-colorable; `ϕ` unsatisfiable ⇒ `α(G_ϕ) < δ |V(G_ϕ)|`. Running time and output size are polynomial in the binary encoding of `ϕ`, with constants depending on `δ`. It suffices to prove it for rational `δ`.

**Corollary 1.2.** For all fixed integers `3 ≤ k ≤ c`, it is NP-hard to distinguish `k`-colorable graphs from non-`c`-colorable graphs (take rational `δ < min{1/3, 1/c}`; a `c`-colorable graph has an independent set of density `≥ 1/c`).

Lean: `Main.lean` proves `mainTheoremReal : ∀ δ : ℝ, 0 < δ → δ < 1/3 → Nonempty (RealGraphReduction δ)`, where `RealGraphReduction δ` (`Model.lean`) packages `reduce : List Bool → Graph`, a `Turing.TM2ComputableInPolyTime` certificate with finite alphabets, a polynomial output bound on the explicit adjacency-matrix encoding `graphBits`, `completeness : φ.Satisfiable → ThreeColorable`, and `soundness : ¬φ.Satisfiable → independenceNumber < δ * vertices`. The hypothesis `δ < 1/3` is unused in the Lean proof (`_hδ3`); `finite_graph_reduction` (`Reduction/Simple.lean`) needs only `0 < δ`. Corollary 1.2 is not formalized as far as I saw.

## 3. Soundness architecture

Fix `L = 64` and an independent set `A`; `A ⊆ X` its locations, so `dist(A, TA) > 1/8` (5).

Extend to each torus `T^{M_i}` by McShane `g_q(x) = min_y (f(y) + L d_∞(x,y))`, clip to `[−1,1]`, oddify `F_q = (g̃_q(x) − g̃_q(Tx))/2`; compatibility (7) `|F_j(x) − F_i(x∘π_{ij})| ≤ 2L/D` by rounding to the grid. ## 5. Self-contained finite/algebraic lemmas suitable for ∏ ℤ/b_i

Circle cost on `ℤ/D`: `circleCost x y = min((x−y).val, D−(x−y).val)`; `dist(toAddCircle x, toAddCircle y) = circleCost x y / D`; sup over coordinates gives the `ℓ^∞` metric on `(ℤ/D)^M`; the antipode `x ↦ x + D/2` (D even) is an involutive isometry; coordinatewise mixed-radix versions are immediate.

Walsh/character orthogonality and Parseval on `{0,1}^n` (`walsh_parseval`, `fourier_parseval`); truncation to `S` equals the coordinate conditional expectation (`truncate_eq_coordinate_mean`); `E(f − E[f|x_S])² = Σ_{supp s ⊄ S} f̂(s)²` (`truncate_error`); `D_i` kills coefficients with `i ∉ s` (`fourier_diff`); `Σ_s |s| f̂(s)² = Σ_i E(D_i f)²` (`weighted_fourier_energy`); `T_ρ` acts by `ρ^{|s|}`; Bonami `‖T_{1/2} f‖_4^4 ≤ ‖f‖_2^4`. All generalize to `∏ ℤ/b_i` with characters.
4. Friedgut-type junta on `{0,1}^N` with L¹ influences: `boolean_junta_error` and `boolean_junta_uniform` (`J` depends only on `L, u`).
5. ## 6. Surprises, possible issues, unclear points

- The Lean does not use Austin's theorem. The dimension-independent junta theorem is proved via Boolean hypercontractivity (Bonami with noise 1/2) plus dyadic discretization of `[0,1]^n` and a Rademacher-based total-variation bound; Lemma 2.3 is then obtained without orthogonal Efron–Stein decomposition, at the cost of an extra `4^J` in `β` (`β = √(ε/(4·4^J J))` vs. paper `√(ε/(4J))`). The paper's Lemma 2.3 proof as written relies on `‖G‖² ≤ Σ_{i∈S} D_i²`, which is fine but differs from the Lean route.
- The Lean reproves the PCP theorem (Dinur-style, `Expansion/` and `PCP/`), parallel repetition (`Repetition/`, Holenstein-type bound), and builds explicit `TM2` machines with polynomial-time certificates (`Machines/`, `Encoding/`, ~50k lines), whereas the paper cites Theorem 2.1 and asserts Prop. 3.1 informally. Directory names are unreliable: `Fourier/Fourier.lean` and `Expansion/Supported.lean` are junta files (`BooleanJunta` namespace), while `Fourier/Walsh.lean` etc. are Håstad-namespace PCP files.
- Lean restricts `P = 2^k` (paper: any even `P`), fixes `ε = δ/10` (paper `ε < δ/8`), uses `r = n+1` layers, and its `actual_aligned_fiber` needs `2 ≤ s`; the main theorem never uses `δ < 1/3`.
- Paper eq. (6) and the remark "equals 1 on A" need `dist(Tx, A) ≥ 1/32` for `x ∈ A`; this follows from (5) but is only implicit. The Lean `oddBump_eq_one` states this explicitly.
- Paper (21)–(22): the comparison `|H − h_{I,t|I}(θ')| ≤ 2L/D < γ` and `‖h − g‖ < γ` are combined to `‖Q_i H‖² < (2γ)²`; the Lean `zero_influence_bound` requires `c < γ` strictly and the same `(2γ)²`, consistent.
- The alignment map in Lean is `a : M → Fin r` with `∀ x, a x ∈ B` (paper `a : M_* → B`), and `DistributionalAlignment` quantifies over arbitrary `M : Type` with `DecidableEq`, matching the paper's "any set `M_*`" and label-universe independence.
- The paper's Remark 8.1 (terminating search for the finite alignment data) is not formalized; all constants are obtained by classical existence (`noncomputable`), which matches the paper's statement that no algorithm computing constants from `δ` is asserted.
- Nothing in the paper looked wrong on this reading; the only places requiring care are the strictness bookkeeping in (5)/(30) and the order of quantifiers in §7 (`d` before `r, µ`, before `σ`, before the alphabets), which the Lean `finite_source_soundness` follows exactly.
